Tunebook Editor

tunebook identities & page indexes

Browse

Every tunebook this suite has data for, ported over from tunebook-index.js. This is the same reference view as Compile's Tunebook Index tab. To add or correct a book's details or its page index, use the Edit Book tab — this view is for browsing. You can also load a richer per-song index file (like edition-indexes/VPH2024.json) for a book below — its extra fields (meter, key, attribution, source) will show inline here once loaded.

Edit Book

Add a new tunebook, or edit an existing one's details and page index by hand. This tool is meant for the hand-labor of building the conceptual structure — if you already have a full set of page/title data collected, adding it row by row here isn't the goal; that's better done directly against tunebook-index.js.

⚠ Renaming moves this book to a new key that old references can't find.

Page Index

Export

Package one book from your working copy as a contribution file to send the maintainer for review. This does not generate or replace tunebook-index.js, and exporting doesn't make a book available in Capture or Compile — accepted contributions may appear in a future Master Tunebook Index release.
